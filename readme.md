Physical Modeling Modal synthesizer on STM32F769i-Disco board, with touchscreen support and built-in effects.


- 16-band resonator filterbank
- Spectrum interpolation/morphing
- Stereo delay effect
- Stereo reverberation effect
- Touchscreen support
